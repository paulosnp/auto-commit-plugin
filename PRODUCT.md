# Caveman Commit

## Register

product

## Users

Desenvolvedores no VS Code, durante a revisão das alterações locais antes de um commit.

## Product Purpose

Gerar, revisar, editar e copiar mensagens Conventional Commits em pt-BR. O usuário
executa o commit fora da extensão. Codex CLI e Claude Code CLI são os providers.

## Brand Personality

Simples, discreta, direta. Referência solicitada: aplicativo ChatGPT para Windows.

## Anti-references

Para este redesign, evitar excesso de badges, cartões dentro de cartões, sombras
decorativas e identidade ilustrada que perca legibilidade em ícones pequenos.

## Design Principles

- Mensagem de commit é o conteúdo principal.
- Copiar, editar e regenerar são ações explícitas e próximas do conteúdo.
- Mostrar detalhes de provider/modelo de forma secundária.
- Preservar a integração com os temas e atalhos do VS Code.
- Confirmar cópia somente depois da resposta da extensão.

## Accessibility & Inclusion

Padrão adotado para implementação: navegação por teclado, foco visível, contraste
WCAG AA, suporte a alto contraste, zoom e movimento reduzido.
